Dashboard Hub Layout Overhaul

Main workspace hub representing active operations, analytics charts, and recent events.

LEGACY PAIN POINTS
  • Giant welcome banner takes up 1/3 of the page with high-contrast text and a basic blue gradient.
  • Stat cards use bold, colored icons that clash, looking like a dashboard for children.
  • Recharts container has excessive margins with default, heavy horizontal axis grids.
PREMIUM REDESIGN SPEC
  • Low-Profile Welcome Row: Compact title block integrating the calendar directly alongside standard breadcrumbs.
  • Refined Stat Widgets: Muted monochrome gray icons that animate into an active glow. Smooth micro-scale hovered stats cards.
  • Premium Plotting Grid: Floating dots or high-contrast crisp AreaChart featuring zero margins, transparent background grids, and deep HSL gradient shadows.
💻 View representation: Stats grids and elegant Area charts merge flush into the 2-panel canvas, framing reports beautifully.

Articles, Recipes & Roundups Lists

Shared data table view (`ContentListBase.tsx`) presenting draft and published collections.

LEGACY PAIN POINTS
  • Massive, highly colored cards at the top for stats block vertical workspace space before the actual table is visible.
  • Row hover changes background color to a stark solid gray instantly with zero transitions.
  • Table headers are thick, bold text that stands out too much compared to actual data.
PREMIUM REDESIGN SPEC
  • Compact Header Rails: Restructure layout so page actions, filters, and searches live in a single flush header.
  • Fluid Row Transitions: Implement a `duration-200` hover shift that adds a subtle drop shadow and slides visual action triggers in on the right.
  • High-legibility typography: Muted table headers (`uppercase text-[10px] font-bold text-muted-foreground/80 tracking-wider`).
🗂️ View representation: Tables blend with subtle card wraps. Rows feature delicate author avatars and status indicators.
🖼️

Media Library Layout

Asset visual grids, direct image slot uploader, and image metadata panels.

LEGACY PAIN POINTS
  • Grid items have variable sizes, making scanning files feel unorganized and uneven.
  • Metadata uploader covers files abruptly.
  • No visual hover clues for image specifications (dimensions, file type).
PREMIUM REDESIGN SPEC
  • Mathematical Masonry Grid: 1:1 aspect-locked preview thumbnails with delicate card radii (`rounded-lg`).
  • Glass Hover Metadata: Muting overlays displaying file properties (e.g. `1200 x 800 | PNG`) in tiny uppercase labels.
  • Pulsing Upload Canvas: Drag-and-drop zones outlined in dash borders that pulse with a glowing ring during transfer states.
🖼️ View representation: A stunning grid of recipe snaps with rounded covers and glassmorphic quick-detail tags.

Hierarchical Category Manager

Nesting category tree workspace with order triggers and meta columns.

LEGACY PAIN POINTS
  • Nesting trees look like plain, indented text bullet points, making hierarchy difficult to trace.
  • Controls and counts (`cached_post_count`) clutter the tree row.
PREMIUM REDESIGN SPEC
  • Nesting Path Guides: Custom vertical lines linking child items back to their parents.
  • Subtle Grab Drag Handles: Integrated drag dots (`lucide-grip-vertical` in soft slate).
  • Secondary Detail Canvas: Selected category info opens in a beautiful right-hand panel, keeping the primary tree clean.
🌳 View representation: Nested category lists with connecting thread indicators, count badges, and hover command buttons.

Authors & Profiles Dashboard

Author card indexes, avatars uploads, and system configurations.

LEGACY PAIN POINTS
  • Card list of authors feels blocky with full-width profiles.
  • Avatar crop uploader is basic, lacking upload guides or previews.
PREMIUM REDESIGN SPEC
  • Premium Profile Grid: Minimal card slots featuring circular avatars with double border rings.
  • Author Detail Split: Left-side focus on avatar and status badges, right-side handles bio copy and social grid fields.
  • Active post counters: Embedded HSL pill counters for user contributions.
👥 View representation: Elegant author cards detailing bios, system permissions, and visual uploader guides.

Settings & Pages Configuration

Multi-panel workspace setup containing General, SEO, Social, and AI fields.

LEGACY PAIN POINTS
  • Settings menus are generic rows with inconsistent font sizing.
  • Save action bar is basic, easily overlooked at the top right.
  • AI field controls clutter basic layouts.
PREMIUM REDESIGN SPEC
  • Dual-Navigation rails: Crisp secondary sidebar containing general settings tabs.
  • Interactive Sticky Action Bar: Floating action block that glides up from the bottom when dirty state is triggered.
  • Collapsible Control Slots: Advanced parameters are hidden under high-end accordion sections.
⚙️ View representation: Dual settings rails, stacked input groups with clear labels, and floating action bars.
