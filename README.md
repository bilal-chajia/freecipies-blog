# 🍽️ Free Recipes Blog

A modern web application dedicated to **healthy, diet-friendly, and easy-to-make recipes**. This platform helps users discover nutritious meals and maintain a balanced lifestyle.

## 🚀 Getting Started

### Clone the repository
```bash
git clone https://github.com/bilal-chajia/freecipies-blog.git
cd freecipies-blog
```

### Install dependencies
```bash
npm install
```

### Run the project
```bash
npm start
```
