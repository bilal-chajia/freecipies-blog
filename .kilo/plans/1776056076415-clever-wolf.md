# Plan: Update schema.sql Comments for R2 Keys Migration

## Context

`schema.sql` is the **single source of truth** for the database. Its JSON schema comments are referenced by developers and AI agents. After the R2 keys migration, variants now store `r2_key` instead of `url`. The comments must reflect this.

**Key principle:** `r2_key` is stored in DB. `url` is built dynamically at read time via `buildImageUrl(r2_key)` → `/api/images/{r2_key}`.

All changes are **comment-only**. No SQL DDL changes needed — the column types (`TEXT`) don't change.
